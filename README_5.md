---

## 🌿 About

Runjo Stores is a neighbourhood grocery shop serving the Kamiti Corner community in Nairobi, Kenya. This repository contains the official website — a single-page HTML site that lets customers browse products, place orders, and pay via M-Pesa, all from their phone or computer.

---

## ✨ Features

- 🥦 **Product Catalogue** — Browse fresh vegetables, fruits, eggs and rice with prices in Ksh
- 🛒 **Online Order Form** — Customers can place orders with name, phone, and item list
- 💚 **M-Pesa Pochi la Biashara** — Clear payment instructions with number 0712 778 283
- 💬 **WhatsApp Integration** — Floating button for instant customer contact
- 📍 **Store Info** — Location, opening hours and contact details
- ⭐ **Customer Reviews** — Testimonials from happy customers
- 📱 **Mobile Friendly** — Works great on all screen sizes

## 🚀 How to Deploy (Go Live)

### Option 1 — Netlify Drop (Easiest, free)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop `index.html`
3. Get a live link instantly

### Option 2 — GitHub Pages (Free)
1. Rename `runjo-stores.html` to `index.html`
2. Push to this repository
3. Go to **Settings → Pages → Deploy from main branch**
4. Your site will be live at `https://yourusername.github.io/runjo-stores`

### Option 3 — Custom Domain
Buy a `.co.ke` domain (~Ksh 1,200/year) from providers like:
- [Truehost Kenya](https://truehost.co.ke)
- [Kenya Website Experts](https://www.kenyawebsiteexperts.com)

Then connect it to your Netlify or GitHub Pages site.
